# 🚍 Bus Management System for KR Mangalam University

A smart bus tracking and route management system designed to make student commutes more efficient, reliable, and transparent. Built by a team of first-year BTech CSE students to solve real-world problems faced by educational institutions.

## 📌 Features
- Real-time GPS tracking of college buses
- Separate dashboards for students and staff
- Notifications for bus delays and cancellations
- Route and schedule management for administrators
- Feedback system for students
- Designed with scalability and future integrations in mind

## 🛠️ Technologies Used

### Frontend:
- HTML
- CSS
- JavaScript
- Bootstrap

### Backend:
- Python (Flask)
- SQLite

### Tools:
- Replit (for live collaborative development)
- Jinja2 Templating

## 🚀 Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/bus-management-system.git
   cd bus-management-system
   ```

2. Install the dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Run the application:
   ```bash
   python app.py
   ```

4. Open your browser and visit:
   ```
   http://localhost:5000
   ```

## 🧪 Usage
- Students can view live bus location and receive real-time alerts.
- Staff can manage bus routes, schedules, and review student feedback.
- Admin dashboard provides a complete overview of system activity.

## 📊 Future Scope
- Google Maps API integration for live route tracking
- Extend to schools and other universities
- Parent logins for monitoring child commute
